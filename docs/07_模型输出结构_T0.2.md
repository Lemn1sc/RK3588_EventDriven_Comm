# T0.2 · 两个模型的输出结构（实测）

> 数据源：ultralytics 自带 `bus.jpg`（6 目标：1 bus + 4 person + 1 弱检测）。
> 复现：`python scripts/inspect_models.py`，可视化存 `data/recordings/{detect,pose}/`。

## 检测模型 yolov8n（事件端 / 边缘角色）

`results[0].boxes`：

| 属性 | shape | 含义 |
|------|-------|------|
| `boxes.xyxy` | (N, 4) | 像素框 x1,y1,x2,y2 |
| `boxes.xywhn` | (N, 4) | 归一化 中心x,中心y,宽,高 |
| `boxes.conf` | (N,) | 置信度 |
| `boxes.cls` | (N,) | 类别编号（COCO 80 类；person=0） |

- `model.names[cls]` 拿类别名。跌倒检测只关心 `person`(0)。
- **高宽比 = h/w** 是跌倒的关键线索：站立约 2~3，跌倒/躺卧会 < 1。
  实测站立行人高宽比 1.9~3.8，公交车 0.5。

## 姿态模型 yolov8n-pose（远端角色 / 跌倒判定）

`results[0].keypoints`：

| 属性 | shape | 含义 |
|------|-------|------|
| `keypoints.xy` | (人数, 17, 2) | 像素坐标 |
| `keypoints.xyn` | (人数, 17, 2) | 归一化坐标 |
| `keypoints.conf` | (人数, 17) | 每点可见度 0~1 |

- 遮挡/出画的点坐标返回 `(0,0)` 且 conf 低（实测 left_ear conf=0.42），
  **判定时须先按 conf 阈值过滤**，否则 (0,0) 会污染几何计算。

## 对 T0.3 的输入

8 维事件向量可直接从检测输出构造：
`event_type`←cls、`confidence`←conf、`bbox`←xywhn 或 xyxy 归一化、
`has_event`←是否有 person、`severity`←可综合 conf + 高宽比异常。

跌倒判定几何量（远端 pose）建议用：
肩中点↔髋中点连线与垂直方向夹角、髋↔踝高度差、整体包围盒高宽比。
