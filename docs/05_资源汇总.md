## 导出 / 转换命令速查

```bash
# 导出 ONNX（PC）
pip install ultralytics
yolo export model=yolov8n.pt format=onnx opset=12 simplify=True

# ONNX → RKNN（WSL2/Linux，rknn-toolkit2）
# 见 scripts/ 下转换脚本，核心：
#   rknn.config(mean_values=[[0,0,0]], std_values=[[255,255,255]], target_platform='rk3588')
#   rknn.load_onnx(...); rknn.build(do_quantization=False); rknn.export_rknn(...)
```

## 关键注意事项

- **版本匹配是最大的坑**：rknn-toolkit2 版本必须与板端 RKNPU 驱动匹配。
  板子到手先跑 `cat /proc/rknpu/version`。
- 先 FP16 不量化跑通，再做 INT8 量化（需校准图集）。
- RK3588 有 3 个 NPU 核：YOLO 用 CORE_0，GRU 用 CORE_1，避免抢占。
- WiFi 传输用 UDP（低延迟），靠策略鲁棒性容忍丢包。
