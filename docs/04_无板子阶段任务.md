## T0.1 环境搭建（半天）✅ 配置就绪

Windows 上先装算法环境（不需要 WSL）。已提供依赖清单与脚本：

**方式 A（推荐，一键）**：双击运行 `scripts/setup_env.bat`

**方式 B（手动）**：
```bash
conda create -n rk python=3.10 -y
conda activate rk
pip install -r requirements.txt
python scripts/check_env.py     # 看到 "环境就绪 ✓" 即通过
```

`check_env.py` 会报告 CUDA 是否可用；若显示 `CUDA 可用: True` 且设备为 RTX 2050，
说明显卡已接入，后续 yolo 推理 / GRU 训练会自动用 GPU。

rknn-toolkit2 仅 Linux，放到 T0.9（用 WSL2），当前阶段不阻塞。

## T0.3 定义数据契约（半天）🔶 事件向量已完成

在 `src/common/` 里固化三样东西，后面所有模块都依赖：
- **事件向量（8 维）**：见 `02_技术方案.md` — ✅ 已完成并验证
- **状态向量（12 维）**：GRU 输入 — ⏳ 待队友
- **通信协议**：UDP 包头格式（事件类型 / 长度 / 时间戳 / payload）— ⏳ 待队友

**已落地（事件向量部分）**：
- `src/common/event_vector.py` — 8 维契约实现。`EventVector` 结构体 +
  `to_array()/from_array()` 定长 float32 往返；索引常量（`IDX_*`）供下游按名取值；
  `EventType` 枚举（NONE / PERSON / SUSPECTED）；`NONE_EVENT` 作无人帧规范表示。
  入口 `event_from_result()`（吃 ultralytics Results）与
  `event_from_detections()`（纯 numpy，框架无关）。
- `scripts/check_event_vector.py` — 合成数据自检，**不依赖 ultralytics/torch**，
  任何环境可跑：往返一致 / severity 合成 / 多人挑主目标 + 类别阈值过滤。
- `scripts/check_event_vector_real.py` — 真实模型输出验证（需 rk 环境）：
  确认 `boxes.xyxyn/conf/cls` 取值路径、dtype、归一化范围，
  并验两条入口（Results 路径 vs numpy 路径）结果一致。

**关键设计决定**：
- 一帧只表征「最严重的主目标」，多人取 severity 最高者（不是置信度最高者）。
- `severity = 置信度 × 高宽比异常度`，低置信自动打折，抑制鬼影框误报。
  高宽比 ≥1.5 视为直立（异常度 0），≤0.7 视为躺卧（异常度 1），中间线性插值。
- 时序判定（高宽比突变 / 停留超时 / 位置异常）**不在此层**，属 GRU 职责，
  边缘端只出向量、不做通信决策。

实测（`bus.jpg` / `zidane.jpg`，见 `docs/07`）：直立行人 h/w 1.9~3.8 → severity 0，
判 PERSON 不触发卸载；zidane 那个 h/w=0.91 的扁框 → severity 0.611 → SUSPECTED；
空帧 → 全零向量。非 person 类（bus/tie/stop sign）均被正确忽略。

> ⚠️ 已知局限：`zidane.jpg` 里那位其实是**站着**的，只因上半身占满画面、
> 下半身被画面边缘截断，h/w 才降到 0.91 被判 SUSPECTED。
> 说明**纯高宽比无法区分「真跌倒」与「框被边缘截断」**。这不是 bug，
> 是单帧几何量的固有上限 —— 恰好是 T0.6 引入 GRU 的动机：
> 截断框会持续多帧稳定存在，而跌倒是高宽比的突变，时序可分。
> 记录在 `docs/06_问题记录.md`。

## T0.4 localhost 全链路模拟（1-2 天）★最高价值

不需要两台设备，一台 PC 开两个进程，`127.0.0.1` 通信：

- `src/edge_node/edge_main.py`：读视频 → yolov8n 检测 → 决策(先用固定规则) → 发帧
- `src/remote_node/remote_main.py`：收帧 → yolov8n-pose → 回传关键点
- `src/transport/`：UDP 收发封装

跑通后，整个"事件端→控制端→WiFi→远端"闭环就在一台电脑上验证完了。
**板子到手后，只需把 edge_node 的检测换成板端 RKNNLite，其余不动。**
